MindOrbit

MindOrbit is a modern, dynamic blog website designed for sharing thoughts, articles, and insights. It provides a clean, user-friendly platform where writers can publish engaging content and readers can seamlessly explore diverse topics orbiting the tech, lifestyle, and creative worlds.

🚀 Features

• User Authentication: Secure signup and login functionality for authors and readers.
• Content Management: Full CRUD capabilities allowing authors to create, read, update, and delete blog posts.
• Rich Text Editing: Interactive editor to format text, embed links, and add images effortlessly.
• Responsive Design: Optimized experience across mobile, tablet, and desktop screens.
• Categorization & Tags: Easy discovery of content filtered by specific topics and tags.
• Comments Section: Interactive space for reader engagement and feedback on posts.

🛠️ Tech Stack

• Frontend: HTML5, CSS3.
